# CPP01 - 42 | [FRENCH VERSION] *english below*

## 📚 Description

Le module CPP01 approfondit la gestion de la mémoire en C++, notamment avec les pointeurs, les références et l'allocation dynamique (**new / delete**).

---

## 🛠️ Notions abordées

* Allocation dynamique
* Pointeurs vs références
* Durée de vie des objets
* Manipulation de chaînes de caractères

## 📚 Description

CPP01 expands on memory management in C++, with a focus on pointers, references, and dynamic memory allocation using **new** and **delete**.
